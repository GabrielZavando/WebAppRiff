## Requirements
### Requirement: Husky activated via prepare script
The root `package.json` SHALL declare a `prepare` script (`husky`) so that installing dependencies activates the Git hooks path (`.husky/`).

#### Scenario: Prepare script present
- **WHEN** the root `package.json` is inspected
- **THEN** `scripts.prepare` equals `husky` and the `.husky/` directory exists in the repository

### Requirement: commit-msg hook validates Conventional Commits
The `.husky/commit-msg` hook SHALL run commitlint against the commit message, rejecting commits whose message violates the rules in `.commitlintrc.json`.

#### Scenario: Conventional message accepted
- **WHEN** a commit is created with message `feat(web): add hero banner`
- **THEN** the `commit-msg` hook passes and the commit is created

#### Scenario: Non-conventional message rejected
- **WHEN** a commit is attempted with message `cambios varios`
- **THEN** the `commit-msg` hook fails with a commitlint error and no commit is created

### Requirement: No pre-commit side effects introduced
The migration SHALL NOT add lint-staged or test execution to `pre-commit`; the sample `pre-commit` hook generated by `husky init` SHALL be removed or emptied.

#### Scenario: Commit speed unaffected by hooks
- **WHEN** a regular commit is created
- **THEN** only `commit-msg` validation runs and no pre-commit lint/test command executes
